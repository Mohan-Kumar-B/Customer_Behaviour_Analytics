📊 Customer Behaviour Analysis

An end-to-end Data Analytics project analyzing customer purchasing behaviour using Python, SQL, and Power BI.

🎯 Project Objective

To analyze customer behaviour, purchasing patterns, product performance, and customer preferences and convert the findings into actionable business insights.

🛠️ Tools & Technologies
🐍 Python — EDA & Data Cleaning
🐼 Pandas — Data Manipulation
🐘 PostgreSQL — Database & SQL Analysis
🗄️ SQL — Business Queries & Data Analysis
📊 Power BI — Interactive Dashboard
🎨 Gamma — Presentation
📝 Report — Business Insights & Findings

🔄 Project Workflow

Dataset → Python EDA → Data Cleaning → SQL Analysis → Power BI Dashboard → Report → Presentation

🔍 Key Analysis
👥 Customer demographics
💰 Revenue & purchase analysis
🛍️ Category performance
🔄 Purchase frequency
⭐ Review ratings
📋 Subscription behaviour
🚚 Shipping preferences
💳 Payment methods
📊 Power BI Dashboard

The interactive dashboard includes:

Total Customers
Average Purchase Amount
Average Review Rating
Subscription Status
Revenue by Category
Sales by Category
Revenue by Age Group
Customers by Purchase Frequency

🎛️ Interactive Filters:
Subscription Status • Gender • Category • Shipping Type

💡 Key Outcome

The project transforms raw customer data into clear business insights that help understand:

Customer behaviour → Purchasing patterns → Product performance → Customer preferences
